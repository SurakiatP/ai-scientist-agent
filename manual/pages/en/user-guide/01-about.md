## What is this guide

This guide explains how to use AI Scientist, a web assistant for academic research. You ask a research question in Thai or English. The system plans search terms, searches scholarly sources, writes an answer from what it finds, and checks that the DOI, PMID or arXiv ID of each reference exists. You can then turn the answer into a report.

Each chapter starts from what the reader wants to do and follows the real screens. Button and menu names in quotation marks match what you see on screen. The pictures use invented test data, not real user data.

## Reading order

- Start with [[getting-started]], then read [[ask-a-question]] and [[read-sources]]
- If you have your own documents or data, see [[ask-documents]] and [[analyze-data]]
- To turn an answer into a report, see [[create-report]]
- Before you use an answer for real, read [[limits-and-safety]] and [[data-and-privacy]]

## Information pages on the website

The first page of the system has menus “How it works”, “FAQ” and “Product” that describe the system in brief. You do not need them to work in the chat. The “Guide” menu on the first page still says that the guide is in development.
