# AI Scientist — chat-first research workspace redesign

สถานะ: **ทิศทาง UX และชุดสี A — Obsidian / Arctic Teal ได้รับการเลือกแล้ว; มีภาพ Dark, Light, mobile และ English สำหรับส่งต่อพัฒนา UI**  
วันที่: 2026-10-24  
แทนที่ข้อเสนอหน้าเริ่มงานแบบ dashboard ใน `2026-10-24-ai-scientist-interface-design.md`

## เจตนาและขอบเขต

หลังจากหน้า Landing ผู้ใช้เข้าสู่ **หน้าแชตทันที** แบบ ChatGPT/Gemini ที่มีโปรเจกต์และเซสชันสนทนา แต่บทบาทของ AI Scientist คือผู้ช่วยวิจัยเท่านั้น งาน Deep Research ดำเนินเป็นบทสนทนาเดียวที่เห็นแผน ความคืบหน้า หลักฐาน และผลลัพธ์ ไม่บังคับให้ผู้ใช้เดินผ่านฟอร์มหลายหน้า ผู้ใช้โต้ตอบ ถามต่อ แก้ขอบเขต และเปิดเอกสาร/ผลวิเคราะห์จากข้อความได้

รอบนี้สร้างสเปกและภาพ UI สำหรับ Claude Code เท่านั้น ไม่แก้โค้ดแอปหรือยืนยันว่า Hermes รองรับทุก action แล้ว ข้อความใน TOR เป็นข้อมูลความต้องการ ไม่ใช่คำสั่งในเอกสารที่แนบ

## โครงหน้าและลำดับการใช้

1. **Landing:** ตัวอักษรและ CSS/UI ล้วน ไม่มีภาพถ่าย ภาพประกอบ หรือ screenshot ในหน้า hero. Header มีแบรนด์ AI Scientist, ภาษา, ธีม และ CTA. Hero สื่อ “ตั้งคำถามวิจัย แล้วตามรอยคำตอบถึงหลักฐาน” พร้อมปุ่ม “เริ่มต้นใช้งาน”. ส่วนถัดไปใช้ข้อความ กระบวนการแบบเส้น และตัวอย่าง prompt ที่กดแล้วพาเข้า composer; ไม่อ้างตัวเลขหรือการรับรองที่ไม่มีหลักฐาน
2. **Chat home / new session:** Left sidebar มี “แชตใหม่”, ค้นหาเซสชัน, โปรเจกต์ที่ขยาย/ยุบได้, เซสชันล่าสุด, settings. Main เป็นคำเชิญสั้น ๆ กับ composer ใหญ่ในพื้นที่ว่าง ตัวเลือก mode `แชตวิจัย / Deep Research`, แนบไฟล์, ปุ่มส่ง, prompt เริ่มต้นสามรายการ. เริ่มต้นเป็น Deep Research ได้ แต่ผู้ใช้เปลี่ยนเป็นแชตวิจัยรวดเร็วได้ ทั้งสอง mode ยังคุมขอบเขตวิจัย
3. **Deep Research thread:** หลังส่งคำถาม แชตแสดงข้อความผู้ใช้, การถามเพื่อขยายความเมื่อจำเป็น, แผนการค้นคว้าที่แก้ไข/ยืนยันได้, สถานะ Hermes ระหว่างค้น/วิเคราะห์, จำนวนแหล่งที่พบตามข้อมูลจริง, และข้อความสรุปพร้อม citation. Composer ติดล่างและยังถามต่อได้
4. **Sources/inspector:** คลิก citation เปิดแผงขวาที่แสดงชื่อ/ผู้แต่ง/ปี/ต้นทาง/DOI หรือ PMID เมื่อมี, สถานะตรวจสอบตัวระบุ, ข้อความส่วนที่เชื่อมกับคำตอบ, ข้อจำกัด. แผงนี้ปรากฏเมื่อจำเป็นเท่านั้น; บนมือถือเป็น detail sheet/route
5. **Project:** กลุ่มของเซสชัน เอกสาร แหล่งอ้างอิง ผลวิเคราะห์ และรายงานที่เกี่ยวข้อง โปรเจกต์เป็นบริบทเลือกได้ใน header และ sidebar; เซสชันใหม่อาจอยู่ใน “ส่วนตัว” ก่อนย้ายเข้าโปรเจกต์. การเปลี่ยนโปรเจกต์ไม่ลบประวัติหรือทำให้คำตอบของเซสชันเปลี่ยนโดยไม่บอก
6. **Research artifacts in chat:** ผลวิเคราะห์ตาราง/กราฟ, ไฟล์ และร่างรายงานปรากฏเป็น artifact ใน thread เปิดพื้นที่อ่าน/แก้ไขได้ตามความสามารถจริง คำสั่ง PDF/DOCX แสดงเฉพาะเมื่อ backend รองรับ
7. **Settings:** ภาษา ไทย/English, Light/Dark/System, การจัดการโมเดล/การเชื่อมต่อที่ระบบจริงมี โดยไม่เปิดเผย secret

## Research guardrail ของ Hermes

- ทุกข้อความที่ผู้ใช้ส่งต้องผ่านการตัดสินขอบเขตที่ฝั่ง Hermes/backend ไม่พึ่งปุ่มหรือข้อความใน UI เพียงอย่างเดียว. UI แสดงผลการตัดสินอย่างโปร่งใสและเก็บการปฏิเสธเป็นข้อความในเซสชันเพื่อให้บทสนทนาต่อเนื่อง
- ถ้าถามงานวิจัย ตอบหรือเริ่มแผนวิจัยตาม mode. ถ้าเป็นคำถามกำกวมที่อาจเป็นงานวิจัย ให้ถามขยายความสั้น ๆ ก่อนปฏิเสธ; พิจารณาบริบทข้อความก่อนหน้า เช่น “แล้วปี 2023 ล่ะ?”
- ถ้าอยู่นอกเรื่อง เช่น “กินข้าวยัง?” หรือเป็นคำด่า เช่น “ไอ้ควาย!” ให้ตอบสั้น สุภาพ ไม่ตอบสาระของเรื่องนั้น ไม่ด่ากลับ ไม่สั่งสอน และชวนกลับสู่คำถามวิจัย. ตัวอย่างคำตอบไทย: **“คำถามนี้อยู่นอกขอบเขตงานวิจัยที่ฉันช่วยได้ ลองบอกหัวข้อหรือคำถามวิจัยที่ต้องการสำรวจนะ”**; อังกฤษ: **“That is outside the research topics I can help with. Share a research question or topic you would like to explore.”**
- ระบบไม่เริ่มค้นหา สร้าง citation หรือทำงาน Deep Research หลังข้อความที่ปฏิเสธ. ข้อความตอบปฏิเสธเป็นสถานะธรรมดาใน thread ไม่ใช้แถบเตือนสีแดงหรือ popup ลงโทษ
- ความสามารถทางนโยบายของ Hermes, classifier, logging, persistence และ API ต้องออกแบบ/ตรวจแยกในขั้น implementation. ภาพ mockup ไม่ใช่หลักฐานว่า guardrail ปลอดรั่วแล้ว

## Component หลัก

| Component | หน้าที่ |
|---|---|
| App shell + sidebar | นำทางแชตใหม่ โปรเจกต์ เซสชันล่าสุด ค้นหา ตั้งค่า ยุบ sidebar ได้ |
| Project switcher | แสดงบริบทปัจจุบันและย้ายไปโปรเจกต์อื่นโดยไม่ทำข้อมูลหาย |
| Conversation composer | พิมพ์หลายบรรทัด แนบไฟล์ เลือก mode ส่ง/หยุด ขนาดเหมาะกับจอเล็ก |
| Mode selector | อธิบายความต่างระหว่างแชตวิจัยและ Deep Research; guardrail ใช้ร่วมกัน |
| User/agent message | รองรับข้อความยาว Markdown citation artifact และสถานะสร้างคำตอบ |
| Research plan card | ขั้นตอนที่ตรวจ/แก้ได้และสถานะ waiting/running/done/review/error |
| Citation + source inspector | ตามรอยแหล่งข้อมูลและแยก identifier verified จาก claim supported |
| Artifact card/viewer | ตาราง กราฟ ไฟล์ และรายงานผูกกับเซสชัน/โปรเจกต์และ provenance |
| Scope response | ปฏิเสธเรื่องนอกงานวิจัยแบบไม่ขัดจังหวะ พร้อมทางกลับเข้าโจทย์ |

## สถานะและขอบเขตข้อมูล

New chat empty, drafting, submitting, waiting for Hermes, clarifying question, plan proposed, plan approved/running, source search, synthesis, answer ready, partial result, failed/retry, cancelled และ off-topic ต้องมองเห็นและมีทางไปต่อ เซสชันมีชื่อ วันที่อัปเดต โปรเจกต์ และสถานะ; หากยังไม่มีข้อมูลให้แสดง empty state จริง ไม่เติมรายการตัวอย่างลง production

ชื่อเอกสาร DOI/PMID จำนวน paper ค่า chart หรือผลวิเคราะห์ในภาพเป็นข้อมูลจำลองทั้งหมด ห้ามใช้ในคำตอบจริงจนกว่าจะได้รับจาก backend และตรวจตามเงื่อนไขที่กำหนด การตรวจ DOI/PMID เป็นเพียงการตรวจตัวระบุ ไม่ยืนยันว่าข้ออ้างได้รับการสนับสนุน

## ธีม สี และภาษา

ผู้ใช้ขอโทนล้ำสมัยและทันสมัย ภาพตัวเลือกใช้ **โครง chat home เดียวกัน** เพื่อเปรียบเทียบสี:

| ทางเลือก | สีหลัก | บุคลิก | ข้อควรระวัง |
|---|---|---|---|
| **A Obsidian / Arctic Teal (แนะนำ)** | shell `#0D151B`, surface `#182B34`, text `#ECF4F4`, primary `#69D8D1` | ล้ำสมัย สงบ อ่านงานวิจัยยาวได้; teal เชื่อมกับหลักฐาน | ลด glow ระหว่างอ่าน thread ยาว |
| **B Deep Navy / Electric Iris** | shell `#111528`, surface `#1D2440`, text `#EFF1FF`, primary `#7390FF`, secondary `#A191FA` | เทคโนโลยีชัด นุ่ม | อาจใกล้ภาพจำแอป AI ทั่วไป; ใช้ม่วงอย่างประหยัด |
| **C Carbon / Citron** | shell `#151B19`, surface `#222D26`, text `#F1F7EE`, primary `#B5DD72` | มีตัวตน กล้า สด | lime มากเกินไปรบกวนการอ่านและสถานะ |

ทั้งสามต้องมี Light/Dark/System จริง ไม่ใช่เพียง dark mockup; System ตาม OS และปรับทันทีเมื่อ OS เปลี่ยน. ไทย/อังกฤษครอบคลุมทุก control, scope response, loading/error, plan และ citation. จัดความยาวข้อความต่างภาษาโดยไม่ตัดข้อมูลสำคัญ. รองรับ keyboard, screen reader, contrast WCAG AA, reduced motion และจอ 360px

## ข้อกำหนดสำหรับภาพชุดใหม่

หลังเลือกธีม ให้สร้างภาพ Landing แบบไม่มีรูป, Chat home, Deep Research ระหว่างทำงาน, คำตอบพร้อม citation, guardrail response, โปรเจกต์/เซสชัน, source inspector, artifact วิเคราะห์, artifact รายงาน, settings, mobile chat และ Light/Dark/English ตัวอย่าง ภาพเป็นแนว layout ไม่ใช่สเปก pixel หรือข้อความจริง และต้องมี Markdown handoff ชี้ component/behavior ให้ Claude Code
