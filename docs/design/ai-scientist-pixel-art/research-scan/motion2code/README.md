## ผลการตรวจ

- **frame_diff ทุก 0.25 วินาที** (คะแนน = ผลต่าง RGB เฉลี่ย ยิ่งต่ำยิ่งเหมือน): 0.00 → 10.55, 0.25 → 11.29, 0.50 → 11.66, 0.75 → 11.66, 1.00 → 11.39, 1.25 → 12.21 (แย่สุด), 1.50 → 10.66, 1.75 → 10.50, 2.00 → 10.70 รอบแรกที่ยังไม่ปรับตำแหน่งได้ 13.3–15.9
- **ระหว่างเฟรมของต้นฉบับ** (ทุก 1/24 วินาที ช่วง 0.5–1.5): สูงสุด 16.95 ที่ 0.54 วินาที เพราะต้นฉบับค้างภาพ 4 fps ส่วนโค้ดเคลื่อนต่อเนื่อง ไม่ใช่ความผิดพลาดของรูปทรง เปิด `?fps=4` ถ้าต้องการให้ค้างท่าเหมือนต้นฉบับ (ผมยังไม่ได้รัน frame_diff ในโหมดนี้)
- **จุดต่อลูป** (`diff-seam/`, 1.75–2.0): 10.48–10.70 คงที่ ไม่กระโดด
- **`check_anim.py --runtime`**: ผ่าน — `duration=2`, `seam_end=0.0` (t=0 กับ t=duration เหมือนกันทุกพิกเซล), `seam_last_frame=0.25`, `determinism=0.0`, ไม่มี console error, ไม่มีคำขอนอก allowlist
- ไม่มี `<img>`, `<video>`, SVG `<image>`, canvas หรือ data URI ในไฟล์ ไม่ใช้ CSS animation, `setTimeout` หรือ `requestAnimationFrame` ขับภาพ (GSAP timeline เดียว)

## สิ่งที่ยังต่างจากต้นฉบับ

ไม่ใช่ pixel perfect คะแนน ~10–12 เป็นระดับที่เหลือหลังจากแก้ตำแหน่งและขนาดแล้ว ส่วนที่ต่างคือ:

1. **พื้นผิวพิกเซลและ dithering:** ต้นฉบับมีขอบหยัก เสียงรบกวน และไล่เฉดแบบ pixel art ส่วนโค้ดเป็นสีเรียบ (ตามกฎของ skill: ไม่มี gradient/filter)
2. **เรืองแสง:** จุดข้อมูลและกระจกเลนส์ในต้นฉบับมีขอบฟุ้ง โค้ดไม่มี
3. **หนังสือ:** ต้นฉบับมีขอบหน้ากระดาษที่ฉีกและโค้งแบบสุ่ม โค้ดวาดเป็นรูปหลายเหลี่ยมเรียบ ข้อความบนหน้ากระดาษเป็นแท่งสี่เหลี่ยมคล้ายของเดิมแต่ไม่ตรงทุกแท่ง
4. **ฐานเครื่อง:** ต้นฉบับมีรายละเอียดบล็อกสลับเฉดมากกว่า โค้ดใช้แผ่นเรียบและแถบไฟสถานะ 6 ช่องแบบสลับสว่างคงที่ (ต้นฉบับสลับสว่าง/มืดต่างกันเล็กน้อยทุกเฟรม)
5. **เนื้อหาในกระจกเลนส์:** ต้นฉบับขยายเนื้อหาหน้ากระดาษเล็กน้อยและมีแสงสะท้อน โค้ดแสดงเนื้อหาหน้าเดียวกันขนาดเท่าเดิม พร้อมสีฟ้าอ่อนเคลือบบางๆ
6. **ระหว่างเฟรม:** ต้นฉบับค้างภาพ 4 fps โค้ดเคลื่อนต่อเนื่อง (เปิด `?fps=4` เพื่อค้างท่า)
7. **คีย์เฟรมวัดด้วยสายตาและการหาพิกเซลสีฟ้า** ความคลาดเคลื่อนราว ±3 px

## ปรับสี ความเร็ว ขนาด

ทุกค่าอยู่ในไฟล์ `index.html` ส่วน `<script>` ตอนต้น:

- **สี:** ค่าคงที่ `C` (สีจุดข้อมูลหรี่/สว่าง, สีท้ายแถว) และสีของรูปทรงที่เขียนเป็น `fill="#…"` ในส่วน SVG แต่ละกลุ่มมี id (`#dots`, `#base`, `#book`, `#bracket`, `#arm`, `#lens`) พาเลต: พื้น `#061A23`, กระดาษ `#DDEEEB/#F1F7F4`, ตัวอักษรบนกระดาษ `#4689A5`, เครื่อง `#033949/#045467/#066F82`, ไฟฟ้า `#08F1E7/#2AF9F9`
- **ความเร็ว:** `SPEED` (1 = เท่าต้นฉบับ, 0.5 = ช้าลงครึ่งหนึ่ง) หรือแก้เวลาในแถว `LENS_X`, `LENS_Y`, `LENS_S`, `DOT_*` (`[เวลา, ค่า]`)
- **ขนาดเลนส์:** `LENS_SCALE` ขนาดทั้งฉาก: ตั้ง `width`/`height` ของ `<svg>` หรือของ container ที่ฝัง (viewBox `0 0 528 528` ย่อขยายได้ไม่เสียรูป)

## แนวทางนำไปใช้ในหน้าแชต (Next.js/MUI) — ยังไม่ได้ติดตั้ง

ตั้งใจใช้ระหว่าง Deep Research กำลังค้นหาหรืออ่านแหล่งข้อมูล โดยเป็นภาพประกอบ ไม่ใช่ตัวบอกความคืบหน้า (ตัวเลขจริงยังมาจาก backend ใน `ProgressCard`)

1. **แสดงเมื่อมีงานกำลังดำเนินการเท่านั้น:** render component เมื่อ `turn.status === "running"` และ `mode` เป็น deep (stage ค้นหา/อ่าน) ยกเลิกการ mount ทันทีเมื่อเสร็จ ยกเลิก หรือผิดพลาด ไม่ให้ GSAP ค้างอยู่ (เรียก `tl.kill()` ตอน unmount)
2. **ฝัง SVG เป็น React component** (`ResearchScan.tsx`): ย้ายรูปทรงจาก `index.html` มาเป็น JSX และย้ายฟังก์ชัน `render(t)` กับ keyframes มาไว้ใน `useEffect` ที่สร้าง timeline เดียว ใช้ `gsap` ที่โปรเจกต์เลือกไว้ (ยังไม่มี dependency นี้ ต้องตัดสินใจก่อนว่าจะเพิ่มหรือไม่) หรือขับ `render(t)` ด้วย `requestAnimationFrame` เดียวพร้อมหยุดเมื่อแท็บถูกซ่อน (`document.hidden`)
3. **Light mode:** วางภายในกรอบสี obsidian (`#061A23`, มุมโค้งตามธีม `10–16px`) เพราะสีของภาพออกแบบสำหรับพื้นมืด ไม่ต้องปรับสีตามธีม
4. **`prefers-reduced-motion`:** ถ้า `matchMedia("(prefers-reduced-motion: reduce)")` เป็นจริง ให้ไม่เริ่ม timeline และวาดท่า `?still=1` (ท่า t=0) เป็น SVG นิ่ง
5. **มือถือ:** กว้างสูงสุด ~120–160 px ที่ `xs` (~200 px ที่ `md`) วางในแถวเดียวกับข้อความสถานะ ห้ามอยู่เหนือหรือซ้อนช่องพิมพ์ และไม่บังข้อความ (`pointer-events: none`, `aria-hidden="true"`, ไม่เป็น focus target)
6. **การเข้าถึง:** เป็นของตกแต่งล้วน: `aria-hidden`, ไม่มีข้อความ, สถานะจริงยังอ่านได้จากข้อความของ `ProgressCard`
7. **ไม่ใส่ในหน้า Landing:** component นี้ import เฉพาะจากหน้าแชต/แผงความคืบหน้า และมี test ว่า `app/page.tsx` ไม่ import
8. **ทดสอบ:** unit test ว่า (ก) ไม่ render เมื่อไม่ running (ข) reduced motion ได้ภาพนิ่งและไม่มี timeline (ค) unmount แล้ว timeline ถูก kill
