# Open Notebook — หน้าจอและ Components

บันทึกภาพหน้าจอจากแอปที่รันในเครื่องและสรุปส่วนประกอบที่มองเห็น เพื่อใช้เป็นข้อมูลอ้างอิงในการออกแบบแอปของเรา ภาพเรียงตามลำดับรายการนำทางหลักและลงท้ายด้วยรายละเอียด Notebook.

- วันที่ตรวจ: 2026-10-24
- ที่อยู่แอป: `http://localhost:3001`
- ขนาดภาพ: 1440 × 760 px; ครอบเฉพาะพื้นที่เว็บแอป
- ขอบเขต: หน้ารายการหลักและหน้ารายละเอียด Notebook ที่มีข้อมูลในเครื่อง; ยังไม่มี Source จึงไม่มี Source detail ที่เปิดดูได้.

## สถานะขณะสำรวจ

ในเครื่องมี Notebook ชื่อ `test1` และข้อมูลบทสนทนาอยู่หนึ่งรายการ หน้าค้นหาแจ้งว่ายังไม่ได้เลือก Embedding Model ส่วน Podcasts แจ้งว่าโปรไฟล์บางรายการยังตั้งค่าโมเดลไม่ครบ ภาพเหล่านี้จึงสะท้อนสถานะจริงของ instance ในเวลาที่บันทึก.
